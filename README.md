# MUMY LOG

React, TypeScript, Vite 기반의 목 데이터 프로토타입입니다. Node.js 24와 npm을 사용합니다.

## 로컬 실행

```sh
npm ci
npm run dev
```

개발 서버는 기본적으로 `http://localhost:5173`에서 실행됩니다. `npm run build`는 타입 검사 후 `dist/`에 배포 파일을 생성합니다. `npm run preview`로 빌드 결과를 확인할 수 있습니다.

서비스 정의서 v1.1을 반영한 웹앱 프로토타입입니다. 계정, 모임, 작품과 공동 플레이 기록은 현재 브라우저에 저장됩니다. 서버 인증, 사용자 간 동기화 및 API 수준의 스포일러 접근 제어는 운영 서비스에서 구현해야 합니다.

## 데모 체험

**마이 → 데모 계정으로 체험**에서 역할을 바꿀 수 있습니다.

- **미스터리러**는 금요일의 탐정들 모임장이며 미스터리 클럽과 보드게임 친구들의 구성원입니다. 금요일의 탐정들에서 공동 기록 등록·수정, 기록 관리자 지정, 삭제 및 복구를 할 수 있습니다.
- **하루**는 같은 모임의 기록 관리자입니다. `안개 속의 저택` 기록에 참여해 상세 정보를 볼 수 있습니다. 미스터리러는 모임 구성원으로서 이 세션의 기본 정보까지 열람할 수 있습니다.
- **루체**는 같은 모임의 일반 구성원입니다. **솔**은 이 모임에서 탈퇴했지만 **내 기록**에서 참여했던 `안개 속의 저택`의 상세 정보를 계속 볼 수 있습니다.

**모임 → 내 모임 → 모임 상세 → 플레이 기록**에서는 현재 구성원이 해당 모임의 기록을 볼 수 있습니다. 공동 기록 수정·삭제도 이 경로에서 진행합니다. **내 기록**에는 내가 참여한 기록만 표시됩니다. 샘플 모임 `금요일의 탐정들`의 초대 코드는 `FRIDAY`입니다.

## Vercel 배포

GitHub에 첫 커밋을 푸시한 뒤 Vercel에서 **Add New → Project**를 선택하고 `yeji-dev25/MUMY-LOG` 저장소를 가져옵니다. 루트 디렉터리는 저장소 루트이며, 프리셋은 **Vite**, 빌드 명령은 `npm run build`, 출력 디렉터리는 `dist`입니다. 초기 상태에서는 환경 변수가 필요하지 않습니다.
